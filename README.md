# 🏀 Projeto – NBA

Este projeto foi desenvolvido para o curso **Bolsa Futuro Digital** da **Softex Pernambuco**, com o objetivo de praticar os conteúdos aprendidos nos primeiros módulos do curso, utilizando **HTML**, **CSS** e um pouco de **JavaScript**, além de aplicar conceitos de **responsividade** nas telas.

---

## 🎨 Desafio Escolhido

[Figma – Desafios CodeLab](https://www.figma.com/design/Yb9IBH56g7T1hdIyZ3BMNO/Desafios---CodeLab?node-id=163987-3195&p=f&t=MZ6DAuhG7yRACkQH-0)

Escolhi esse design porque gosto de assistir aos jogos da NBA.  
No layout aparecem algumas siglas, e aqui estão os significados:

- **PPG** → Pontos por jogo  
- **RPG** → Rebotes por jogo  
- **APG** → Assistências por jogo  

### Posições dos Jogadores

- **PG** → Armador  
- **SG** → Ala-armador  
- **SF** → Ala  
- **PF** → Ala-pivô  
- **C** → Pivô
